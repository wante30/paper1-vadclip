\section{Related Work}
\label{sec:related}

\textbf{Weakly supervised video anomaly detection.} With only video-level labels, most methods treat a video as a bag of snippets and train a snippet scorer with a multiple-instance objective that pools the highest scores~\cite{sultani2018real}. Later work refines what those pooled snippets should look like: label-noise cleaning with graph convolution~\cite{zhong2019gcnlnc}, feature-magnitude learning~\cite{tian2021rtfm}, magnitude-contrastive glance-and-focus modelling~\cite{chen2022mgfn}, and memory units with uncertainty regulation~\cite{zhou2023urdmu}. XD-Violence introduced a large multimodal benchmark together with the similarity and distance graph branches for temporal context~\cite{wu2020xdviolence} that VadCLIP retains. These methods, like ours, operate on precomputed snippet features that are resampled to a fixed length during training.

\textbf{Vision-language models for anomaly detection.} CLIP~\cite{radford2021clip} features have become the standard input for weakly supervised detection. CLIP-TSA combines them with temporal self-attention~\cite{joo2023cliptsa}, and PEL4VAD enhances context features with prompts~\cite{pu2023pel4vad}. VadCLIP~\cite{wu2024vadclip} adds a second, prompt-aligned output that scores snippets against learnable class prompts, and follow-up work enriches those prompts with normality guidance~\cite{yang2024tpwng} or spatio-temporal cues~\cite{wu2024stprompt}. A separate line uses large language models, either training-free~\cite{zanella2024lavad} or with multimodal instruction tuning~\cite{zhang2024holmesvad}. All of these model time after the fixed-length resampling step. We build directly on VadCLIP and change two things: what temporal information reaches its shared representation, and which parameters an additional semantic objective may update.

\textbf{Temporal differences and graph modelling.} Explicit temporal differences are an established cue in action recognition: TDN computes differences between neighbouring frames inside the backbone~\cite{wang2021tdn}, TSM exchanges information across time by shifting channels~\cite{lin2019tsm}, and X-CLIP extends image-language pretraining to video with cross-frame communication~\cite{ni2022xclip}. These methods act on frames within a trainable backbone, so a difference layer can be placed anywhere inside it. In weakly supervised detection the backbone is frozen and the only temporal operation before learning is the fixed-length resampling of snippet features, which makes placement relative to that step the design decision rather than an implementation detail. Graph convolution~\cite{kipf2017gcn} underlies the similarity branch we sparsify.

\textbf{Adapting pretrained models.} Parameter-efficient adaptation inserts small trainable modules or low-rank updates into a frozen model~\cite{houlsby2019adapter,hu2021lora}. Prompt learning~\cite{zhou2022coop} and feature adapters~\cite{gao2024clipadapter} apply the idea to CLIP, and ST-Adapter transfers image models to video~\cite{pan2022stadapter}. These methods choose a module to add under a parameter budget. Our second stage adds none: it keeps the architecture fixed and restricts an additional objective to an existing adapter, selected by its position in the prediction pathways rather than by its size.
