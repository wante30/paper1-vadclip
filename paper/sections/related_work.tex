\section{Related Work}
\label{sec:related}

\paragraph{Weakly supervised video anomaly detection.}
With only video-level labels, most methods treat a video as a bag of snippets and train a snippet scorer with a multiple-instance objective that pools the highest scores~\cite{sultani2018real}. Later work refines what the pooled snippets should look like: label-noise cleaning with graph convolution~\cite{zhong2019gcnlnc}, feature-magnitude learning~\cite{tian2021rtfm}, magnitude-contrastive glance-and-focus modelling~\cite{chen2022mgfn}, and memory units with uncertainty regulation~\cite{zhou2023urdmu}. XD-Violence introduced a large multimodal benchmark together with similarity and distance graph branches for temporal context~\cite{wu2020xdviolence}, a design that VadCLIP retains. These methods, like ours, operate on precomputed snippet features that are resampled to a fixed length during training.

\paragraph{Vision-language models for anomaly detection.}
CLIP~\cite{radford2021clip} features have become the standard input for weakly supervised detection. CLIP-TSA combines CLIP features with temporal self-attention~\cite{joo2023cliptsa}, and PEL4VAD enhances context features with prompts~\cite{pu2023pel4vad}. VadCLIP~\cite{wu2024vadclip} adds a second, prompt-aligned output that classifies snippets against learnable class prompts; follow-up work adds normality guidance to the text prompts~\cite{yang2024tpwng} and spatio-temporal prompts for localization~\cite{wu2024stprompt}. A separate line uses large language models, either training-free~\cite{zanella2024lavad} or with multimodal instruction tuning~\cite{zhang2024holmesvad}. We build directly on VadCLIP and change two things: what temporal information reaches its shared representation, and which parameters an additional semantic objective may update.

\paragraph{Temporal differences and graph modelling.}
Explicit temporal differences are an established cue in action recognition: TDN computes differences between neighbouring frames inside the backbone~\cite{wang2021tdn}, and TSM exchanges information across time by shifting channels~\cite{lin2019tsm}. X-CLIP extends image-language pretraining to video recognition with cross-frame communication~\cite{ni2022xclip}. These methods act on frames within a trainable backbone. In weakly supervised detection the backbone is frozen and the only temporal operation before learning is the fixed-length resampling of snippet features; our variation residual targets that step. Graph convolution~\cite{kipf2017gcn} underlies the similarity branch we sparsify.

\paragraph{Adapting pretrained models.}
Parameter-efficient adaptation inserts small trainable modules or low-rank updates into a frozen model~\cite{houlsby2019adapter,hu2021lora}; prompt learning~\cite{zhou2022coop} and feature adapters~\cite{gao2024clipadapter} apply the same idea to CLIP, and ST-Adapter transfers image models to video~\cite{pan2022stadapter}. Our second stage adds no parameters. It restricts an additional objective to an existing adapter, VadCLIP's text-side $\mathrm{mlp}_1$, chosen because it lies downstream of the classification output, so that output is unchanged by construction.
