\section{Introduction}
Intelligent surveillance systems must identify rare abnormal events in long video streams. Video-level labels indicate event presence without the expense of annotating temporal boundaries. Weakly supervised video anomaly detection (WSVAD) learns snippet-level anomaly scores from these labels through multiple-instance learning~\cite{sultani2018real}. Frozen CLIP features~\cite{radford2021clip} supply semantic information for lightweight temporal models. VadCLIP~\cite{wu2024vadclip} combines classification and prompt-aligned semantic outputs within this setting.

Recent detectors improve feature discrimination, temporal context, and prompt learning~\cite{tian2021rtfm,zhou2023urdmu,pu2023pel4vad,yang2024tpwng,wu2024stprompt}. An additional question concerns the \emph{position} at which information and supervision enter the detector. Temporal modeling depends on the evidence retained in its input, while auxiliary objectives can change predictions that share updated parameters. Both dependencies matter when feature compression precedes a model with related outputs.

The first issue arises before temporal modeling. VadCLIP maps each training feature sequence to a fixed length. For long sequences, segment-mean aggregation reduces multiple consecutive snippets to one vector. Similar average appearances can result from very different local feature trajectories, so differencing segment means cannot recover the variation that occurred before aggregation. In the training features used here, 28.0\% of UCF-Crime sequences and 30.4\% of XD-Violence sequences undergo this averaging. Extracting the variation beforehand provides information that the temporal model would otherwise have to infer from compressed appearance features.

The second issue concerns the optimization of the semantic output. In VadCLIP, classification scores weight a pooled video representation that conditions the text prompts. Both outputs also use a shared temporal representation. Applying an additional semantic objective to the entire network can therefore alter the classification output. The text-side adapter, however, lies downstream of the classification computation. This dependency offers a direct way to improve prompt-aligned predictions while keeping an established classifier unchanged.

We address these issues with the placement-aware framework in Fig.~\ref{fig:overview}. Stage~1 computes absolute differences of raw CLIP snippet features before aggregation and fuses the aligned variation statistics through a zero-initialized low-rank residual. It also refines similarity propagation by mixing the original adjacency with a sparse nearest-neighbor term. Stage~2 adds a semantic multiple-instance objective and updates only VadCLIP's existing text-side adapter. The common principle is to preserve temporal evidence before it is compressed and to place auxiliary optimization where it can adapt semantics without moving classification scores.

Component, placement, and objective ablations validate the framework's design. Our contributions are:
\begin{itemize}
\item \textbf{Pre-aggregation variation refinement.} We introduce an aligned temporal residual that supplies explicit snippet-variation statistics to the detector before temporal modeling. Component and pre/post-aggregation comparisons establish the value of this design, complemented by sparse-neighborhood graph refinement.
\item \textbf{Classifier-preserving semantic adaptation.} We derive the update restriction from VadCLIP's computation graph and apply semantic multiple-instance supervision to an existing text-side adapter. Semantic predictions can adapt while classification outputs remain unchanged, without adding inference operations.
\item \textbf{Effective, lightweight refinement.} Experiments on UCF-Crime and XD-Violence show improvements of 0.41 AUC and 1.66 AP points over matched VadCLIP retraining. The original training setting yields a best-run XD-Violence AP of 84.94\%, and neural scoring latency increases by less than 4\%.
\end{itemize}
