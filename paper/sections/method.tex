\section{Method}
\label{sec:method}

We build on VadCLIP~\cite{wu2024vadclip}, which takes frozen CLIP snippet features $X \in \mathbb{R}^{L \times d}$ ($d=512$) and maps each training video to $T=256$ steps with an operator $\mathrm{Agg}$: longer videos are mean-pooled over $T$ uniform segments and shorter ones are zero-padded. A temporal transformer and two graph branches produce a shared representation $h$. The classification output $s^{(1)} = f_{\mathrm{cls}}(h + \mathrm{mlp}_2(h))$ gives snippet anomaly logits. The semantic output pools $h$ with weights from $s^{(1)}$ into a video vector $a$, refines each class prompt with a text-side adapter, $t_c = (t^0_c + a) + \mathrm{mlp}_1(t^0_c + a)$, and scores $s^{(2)}_{j,c} = \cos(h_j, t_c)/\tau$, from which the anomaly probability $p_j = 1 - \mathrm{softmax}(s^{(2)}_j)_{\mathrm{normal}}$ follows. Following VadCLIP, UCF-Crime is reported with $s^{(1)}$ and XD-Violence with $p$. Since $s^{(1)}$ does not depend on $\mathrm{mlp}_1$, the semantic pathway can be adapted without touching the classification pathway.

Our method applies refinement at two positions (Fig.~\ref{fig:overview}): temporal variation is extracted before aggregation (Stage~1), and semantic adaptation is applied after the pathways separate (Stage~2).

\subsection{Pre-Aggregation Temporal Refinement}
\label{sec:pvr}

For a long training video, $\mathrm{Agg}$ averages on average \ucfBinSize{} (UCF-Crime) and \xdBinSize{} (XD-Violence) snippets per segment, so differences of the aggregated sequence only measure change between segment means. We instead compute variation on the raw snippets,
\begin{equation}
  D_1 = 0, \qquad D_t = \lvert X_t - X_{t-1} \rvert, \quad t = 2, \dots, L,
  \label{eq:diff}
\end{equation}
and aggregate it with the same segment boundaries as appearance, $A = \mathrm{Agg}(X)$ and $V = \mathrm{Agg}(D)$, so both streams stay aligned at training and test time. The variation enters through a low-rank residual,
\begin{equation}
  Z = A + \beta\, W_2\, \mathrm{GELU}\big(W_1\, \mathrm{LN}(V)\big),
  \label{eq:pvr}
\end{equation}
with $W_1 \in \mathbb{R}^{128 \times d}$, $W_2 \in \mathbb{R}^{d \times 128}$, and $\beta = 0.2$. $Z$ replaces $A$ as the input of the temporal model and therefore reaches both outputs, at a cost of \pvrParams{} parameters.

The key distinction from an ordinary temporal difference is the order of operations. Segment-level averaging preserves the mean appearance of a segment but not its internal dynamics: two segments can have nearly identical averaged features while one is static and the other contains an abrupt motion. A difference computed after aggregation, $\lvert A_j - A_{j-1} \rvert$, only compares these means and cannot recover what the average discarded. Because $\mathrm{Agg}$ is linear, $\mathrm{Agg}(D)$ is the mean absolute change inside each segment, which is exactly the quantity the post-aggregation difference loses. Sharing the segment boundaries with $A$ keeps the two streams aligned step by step, so the residual can be read as a per-step correction to appearance rather than a separate signal. On videos shorter than $T$, which are only padded, $\mathrm{Agg}$ is the identity and the two orders coincide; the design therefore changes the model only where pooling actually removes information. The residual form, the low rank, and the zero-initialized $W_2$ and bias make training start exactly from the VadCLIP representation and learn the contribution of variation progressively, so the baseline remains reachable if variation is uninformative.

\textbf{Sparse neighbourhood refinement.} As a supporting refinement within Stage~1, we sharpen VadCLIP's similarity graph. VadCLIP thresholds the cosine similarities and normalizes each row with a softmax, but a thresholded entry still receives weight $e^0$ in the softmax, so each snippet stays weakly connected to every other snippet in the window. In long videos these residual weights accumulate over many unrelated snippets and dilute the contribution of the few similar ones. We mix the original graph with a sparse $k$-nearest-neighbour graph,
\begin{equation}
  G = (1-\alpha)\,G_{\mathrm{orig}} + \alpha\,\mathrm{softmax}\big(M_k(S)\big),
  \label{eq:knn}
\end{equation}
where $S$ is the cosine similarity matrix and $M_k$ keeps the $k$ largest entries per row and masks the rest to $-\infty$; we use $k=16$ and $\alpha=0.25$. Mixing rather than replacing keeps VadCLIP's global context, while the sparse term gives each snippet a local neighbourhood whose size does not grow with window length. Both terms are row-stochastic, so $G$ remains a valid propagation matrix, and no parameters are added. We treat this as a supporting component of Stage~1 rather than a separate contribution.

\subsection{Pathway-Restricted Semantic Adaptation}
\label{sec:isa}

VadCLIP trains $s^{(2)}$ with the class-level CLASM objective. We add a binary multiple-instance target on $p$: for a video of valid length $\ell$ and label $y$, let $q$ be the mean of the $\lfloor \ell/16 \rfloor + 1$ largest $p_j$, and
\begin{equation}
  \mathcal{L} = \mathcal{L}_{\mathrm{CLASM}} + \lambda\, \mathrm{BCE}(q, y), \qquad \lambda = 0.1.
  \label{eq:isa}
\end{equation}
CLASM supervises which class a video belongs to, whereas the binary term supervises whether its most anomalous snippets are anomalous at all, which is the quantity $p$ is evaluated on. Optimized over the whole network, however, this objective also changes $h$ and hence $s^{(1)}$, so a gain on the semantic output can be paid for on the classification output.

Stage~2 avoids this by restricting the update to a subgraph. In VadCLIP's computation, $h$ and $a$ are computed before the text-side adapter and $s^{(1)}$ reads only $h$, so
\begin{equation}
  \frac{\partial s^{(1)}}{\partial \theta_{\mathrm{mlp1}}} = 0, \qquad
  \frac{\partial s^{(2)}_{j,c}}{\partial \theta_{\mathrm{mlp1}}} = \frac{\partial s^{(2)}_{j,c}}{\partial t_c}\,\frac{\partial t_c}{\partial \theta_{\mathrm{mlp1}}} \neq 0 .
  \label{eq:grad}
\end{equation}
Stage~2 starts from the Stage~1 model and optimizes Eq.~\eqref{eq:isa} with respect to $\theta_{\mathrm{mlp1}}$ only, with all other parameters frozen. With the parameters before the branch point fixed, $h$, $a$, and $s^{(1)}$ are identical before and after Stage~2, and the semantic output changes only through the refined class prompts $t_c$. The parameter restriction is therefore determined by the computational dependency of VadCLIP rather than by parameter efficiency alone: because the classification output does not depend on the text-side adapter, updating this adapter can modify semantic predictions without modifying classification scores. This lets us add semantic supervision while preserving the original classifier pathway exactly, instead of trading one output against the other through a loss weight. The adapter already exists in VadCLIP, so Stage~2 adds no parameters and no inference cost.

\subsection{Implementation Details}
\label{sec:impl}

Stage~1 follows VadCLIP's released configuration for each dataset and trains for 10 epochs. Stage~2 trains the \mlpOneParams{} parameters of $\mathrm{mlp}_1$ for 3 epochs with AdamW (learning rate $2\times10^{-5}$, weight decay $0.01$), batch size 64 on UCF-Crime and 96 on XD-Violence. The hyperparameters $\beta$, $k$, $\alpha$, and $\lambda$ are shared across datasets.
